# MH2 Chat

MH2 Chat is a modern communication application designed to provide fast, secure, and seamless messaging experiences.

## Features

- Real-time messaging
- Private conversations
- User authentication
- User profiles
- Responsive design
- Fast and lightweight interface
- Firebase-powered backend
- Cross-device accessibility

## Technologies

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Realtime Database
- Firebase Storage
